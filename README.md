# 🧪 The Large SuperDesign Skills Lab

**65 reusable design-system skills** — every one shipped as a loadable agent skill (`SKILL.md`), a full landing-page **demo**, and a **token anatomy diagram** (SVG).

Built by [Rommark.dev](https://www.rommark.dev). Two families:

| Family | Count | Origin |
|---|---|---|
| 🟢 **Production Vercel systems** | 10 | Reverse-engineered from live demos hosted on Vercel ([gallery](https://rommark.dev/)) |
| 🔵 **SuperDesign studies (enhanced)** | 55 | All 45 published systems from [superdesign.dev/design-systems](https://superdesign.dev/design-systems), re-tokenized and upgraded |

---

## 📁 Repository structure

```
├── skills/
│   └── <slug>/
│       ├── SKILL.md      # loadable skill: when-to-use, tokens, layout grammar, do/don't
│       ├── demo.html     # standalone demo site in the system
│       └── diagram.svg   # token anatomy: palette, type scale, components
├── index.html            # visual gallery of all diagrams
├── skills-index.json     # machine-readable index
└── README.md
```

## 🚀 Using a skill

1. Copy `skills/<slug>/SKILL.md` into your agent's skills folder
